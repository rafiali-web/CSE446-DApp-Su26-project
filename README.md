# BountyPulse

BountyPulse is a local Web3 DApp project for the Summer 2026 DApp assignment.

## Current stage

This starter project contains:
- Solidity smart contract: `src/BountyPulse.sol`
- Foundry project structure
- Placeholder folders for tests, deployment scripts, ABI, and frontend

## Required tools

- VS Code
- Foundry (Forge + Anvil)
- MetaMask
- Node.js/npm (for later frontend work)
- Pinata account/JWT (for later IPFS work)

## Start Anvil

```bash
anvil
```

Use Chain ID `31337`.

## Compile

```bash
forge build
```

## Next steps

1. Write `test/BountyPulse.t.sol`
2. Run `forge test`
3. Create `script/DeployBountyPulse.s.sol`
4. Deploy to Anvil
5. Export ABI/address for the frontend
6. Build Pinata/IPFS helper
7. Build Ethers.js frontend
8. Add real-time event syncing
