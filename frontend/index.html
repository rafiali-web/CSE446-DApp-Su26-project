Decentralized micro-bounty and escrow

Escrowed work, settled on-chain.

Post a bounty, receive quotes, lock ETH in escrow and release it only when the work is approved. A 2% protocol fee, on-chain reputation, and an arbiter for disputes.

Files live on IPFS and only the content identifier ever touches the chain, so a two megabyte attachment costs one HTTP request and roughly forty-six bytes of storage instead of millions of gas. Sorting and filtering happen in this browser, on data already fetched by a single free view call.

  1. Connect MetaMask on chain 31337.
  2. Register as a Client or a Freelancer. One address, one account, one role.
  3. Bid, escrow, deliver, claim.
